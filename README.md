# 🎬 BookMyShow Frontend Clone

A basic **BookMyShow frontend clone** created while learning and practicing **HTML and CSS**.
This project focuses on recreating the basic layout and visual structure of the BookMyShow website.

> ⚠️ This is a learning project and is **not affiliated with or connected to BookMyShow**.

## 📌 Features

* BookMyShow-inspired navigation bar
* Search bar section
* Location selection UI
* Sign-in button
* Navigation categories:

  * Movies
  * Stream
  * Events
  * Plays
  * Sports
* Additional navigation options:

  * ListYourShow
  * Corporates
  * Offers
  * Gift Cards
* Recommended Movies section
* Best of Live Events section
* Footer with logo and copyright text
* Responsive viewport setup

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
